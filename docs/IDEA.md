# 프로젝트 아이디어 (IDEA.md)

## 1. 한 줄 소개

팀이 프로젝트 단위로 업무를 등록하고 담당자·마감일·우선순위를 정해, **칸반 보드로 진행 상황을 관리하고 변경 이력과 마감 위험을 한눈에 보는** 웹 서비스입니다.

## 2. 해결하려는 문제

소규모 팀의 업무는 메신저와 개인 메모에 흩어져 있어, 누가 무엇을 언제까지 하는지 한곳에서 보기 어렵습니다.

| 문제 | 현재 상황 | 해결 방법 |
| --- | --- | --- |
| 업무 누락 | 말로 정한 업무가 기록되지 않아 빠진다 | 업무 등록(담당자·마감일·우선순위), 칸반 보드 |
| 진행 상황 불투명 | 회의를 해야 진행 상황을 알 수 있다 | 프로젝트 진행률, 최근 활동 20건 |
| 마감 놓침 | 마감일이 지나서야 지연을 안다 | 마감 임박(3일 이내)·지연 업무 대시보드 |
| 변경 이유 불명 | 마감일·담당자를 누가 언제 바꿨는지 모른다 | 업무 변경 이력(Activity Log) 자동 기록 |

## 3. 대상 사용자

| 사용자 | 역할 | 원하는 것 |
| --- | --- | --- |
| 프로젝트 관리자 | 프로젝트 `OWNER` | 업무 분배, 팀원별 업무량 균형, 마감 관리, 멤버 관리 |
| 팀원 | 프로젝트 `MEMBER` | 내 업무와 마감일 확인, 상태 갱신, 최근 활동으로 현황 파악 |
| 시스템 관리자 | 시스템 `ADMIN` | 전체 계정 조회·비활성화 (P2) |

## 4. 핵심 기능

| 우선순위 | 기능 |
| --- | --- |
| **P0 (MVP 필수)** | 회원가입·로그인(JWT)·내 정보 조회, 프로젝트 CRUD, 이메일로 멤버 추가·목록·제거, 업무 CRUD, 버튼식 칸반(상태 3단계, 우선순위 4단계), 프로젝트 진행률, 변경 이력 자동 기록 |
| **P1 (권장)** | 검색·필터, 댓글, 변경 이력 조회·최근 활동, 마감 임박·지연 대시보드, 내 업무 대시보드, 담당자별 현황, 내 정보 수정, 멤버 역할 변경 |
| **P2 (여유 시)** | 드래그 앤 드롭, Refresh Token, 프로젝트 보관, 관리자 기능 |

P0이 모두 끝나고 테스트를 통과하기 전에는 P1을 시작하지 않습니다.

## 5. 차별화 포인트

1. **업무 변경 이력:** 누가, 무엇을, 이전 값 → 새 값, 언제 바꿨는지 자동으로 남깁니다. 업무가 삭제되어도 이력은 보존됩니다.
2. **마감 위험 대시보드:** 마감 3일 이내 업무와 이미 지난 업무를 따로 모아, 마감을 놓치기 전에 챙길 수 있게 합니다.
3. **SDD 방식 습득:** 명세를 먼저 쓰고 AI로 구현한 뒤 검토·테스트·명세 비교를 반복하는 개발 방식을 팀 단위로 익힙니다.

## 6. 만들지 않는 것

- LLM, RAG, LangChain, AI 에이전트, AI 모델 학습 등 AI 기능 (AI는 코딩 도구로만 사용)
- 실시간 알림(WebSocket), 이메일 발송, 파일 첨부, 외부 서비스 연동
- 보기 전용 역할(VIEWER)

## 7. 기술 스택

React + Tailwind CSS + Axios / FastAPI + Pydantic / MariaDB 10.11 + SQLAlchemy 2.x + Alembic / JWT + bcrypt / pytest + Postman

## 8. 성공 기준

- P0 기능 100% 구현, P0 핵심 API(인증·권한·업무 CRUD) pytest 전부 통과
- 권한 실패 케이스(비멤버 403, MEMBER의 남의 업무 삭제 403) 테스트로 보장
- P1 우선 5개(검색·필터, 댓글, 변경 이력 조회, 마감 임박·지연, 내 업무 대시보드) 구현
- 명세에 없는 API·테이블 0개
- 공통 모듈(인증, API 클라이언트, DB 세션, 예외 처리, 공통 UI)을 스타터킷으로 분리
