- PowerShell에서 `git commit -m`에 큰따옴표가 있으면 메시지가 깨짐 → 메시지 파일 + `git commit -F`.
- `.env`의 `DATABASE_URL`이 비밀번호로 덮어써져 연결 실패 → URL 형식 복구, 비밀번호를 바꿨으므로 `docker compose down -v` 후 재생성.
