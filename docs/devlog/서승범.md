### 문제와 해결
- **명세 빈틈 발견 → 수정(SPEC-CHANGELOG #3, DATABASE-DESIGN v1.1):** `ck_task_activities_field`가 `UPDATED` + `field = NULL`을 통과시킴(`NULL IN (...)` = 알 수 없음 → CHECK 통과). `field IS NOT NULL` 추가, 회귀 테스트 추가. **팀장 승인 필요.**
- `.ini` 파일에 한글 주석 → Alembic 실행 실패(한국어 Windows가 cp949로 읽음). `alembic.ini`·`pytest.ini`는 ASCII만 쓰기로 함.
- 수업 PC 보안 정책이 `black.exe` 실행을 막음 → `python -m black`으로 실행. (SETUP.md에 추가 필요)
- PowerShell에서 `git commit -m`에 큰따옴표가 있으면 메시지가 깨짐 → 메시지 파일 + `git commit -F`.
- `.env`의 `DATABASE_URL`이 비밀번호로 덮어써져 연결 실패 → URL 형식 복구, 비밀번호를 바꿨으므로 `docker compose down -v` 후 재생성.
