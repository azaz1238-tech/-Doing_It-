### 결정
- 프론트 뼈대는 새로 만들지 않고 먼저 작성한 코드를 옮겼다. 토큰 키·401 예외·`loading`·라우트가 문서 규칙에 맞아서다(새로 만들면 약 9h, 옮기면 1h 이내).
- 공통 컴포넌트는 **동잇 UI 시안 v0.3 · 쿨톤**에 맞춘다. 색 토큰은 이미 v0.3 값이었고 컴포넌트만 고쳤다. UI-DESIGN §7 표는 아직 v0.2 값이라 문서 수정이 먼저다(양준석 승인).
- 미리보기는 `features/dev/`에 두고 개발 서버에서만 연다(프론트 폴더는 `core/` + `features/`만, ARCHITECTURE §10-6).
- Input 글자 수(`maxCount`)는 입력을 막지 않고 표시만 한다. 시안 S5가 `34/30`으로 넘친 상태와 오류 문구를 보여 준다.
- ErrorPage(S8 403·404)는 김서현(TASKS T-F0-14). 파일 위치가 `core/ui/`라 TASKS §3 `core/` 주인(최진영)과 겹친다 → 11/17 회의 안건.
- **화면 문구 규칙 (11/16 회의, 전원 승인):** `~합니다`체. SPEC 따옴표 문구는 글자 그대로, 질문은 `~하시겠습니까?`, 문장 끝 마침표 없음. 오류는 프론트가 `code`로 SPEC 문구를 고르고, 모르는 `code`만 서버 `message`를 그대로 보여 준다.
- Avatar는 `user.id`로 색을 고른다. Member 응답은 `user_id`라 `{ id: m.user_id, name }`으로 바꿔 넣는다(API 변경 없음, API-SPEC §4).
- Avatar 글자는 시안처럼 이름 첫 글자: 한글 3자 이름은 성을 뺀 둘째 글자(김민호 → 민), 그 밖(2자·4자·영문)은 첫 글자. 같은 성이 많아 성으로는 구분이 안 된다. (김서현 확인 대기)
- `avatar-1`이 시안 원본 #7084C9가 되면서 기존 `avatar-2`와 겹쳐, 기존 #4F8FAC를 `avatar-2`로 옮겼다(4색 구성은 그대로).
- 확인 창은 ✕ 없이 `취소`·ESC·바깥 클릭으로 닫는다. 본문은 문장마다 줄을 바꾼다(시안 v0.3).
- 프로젝트 삭제 문구는 `'{이름}'을`이 이름에 따라 조사가 틀려 `프로젝트 이름({이름})을`로 (김서현 제안).

### 문제와 해결
- Docker Desktop 설치 실패("One prerequisite is not fulfilled") → Per-user 설치는 Virtual Machine Platform을 켤 권한이 없음 → 관리자 PowerShell `wsl --install`, 재시작 후 다시 설치(Per-user + WSL 2).
- 설치 후 `docker` 명령을 못 찾음 → 설치 전에 열린 터미널이라 PATH가 갱신 안 됨 → 터미널을 새로 연다.
- Toast가 `icons`에 없는 `CircleCheckIcon`·`CircleAlertIcon`을 불러와 **빌드 실패** → 있는 아이콘(`CheckIcon`·`TriangleAlertIcon`·`LogOutIcon`)으로 교체.
- `neutral-800`이 팔레트에 없어 Tailwind 기본 회색이 나옴 → `neutral-900`으로.
- 브라우저에서 `localhost:5173`이 안 열림 → Vite가 IPv6(`::1`)에서만 받음 → `npm run dev -- --host 127.0.0.1`, `http://127.0.0.1:5173`.
- Vite 터미널의 `http proxy error ... ECONNREFUSED` → 백엔드가 켜져 있지 않아서다(정상).
- DB 접속이 멈춤 → Docker Desktop이 일시정지(Paused) 상태 → Resume.
- 첫 커밋에서 "Author identity unknown" → 이 PC에 Git 작성자가 없음 → GitHub noreply 주소로 이 저장소에만 설정(`git config user.email`, `--global` 없이).
- 다운로드 폴더의 시안 이미지가 옛 문구(`~해요`)판 → 김서현이 `~합니다`판으로 다시 뽑아 그 기준으로 대조.
