## 1. 요약

- **A조가 만든 기능 시나리오 35개 모두 ✅.** 실패·버그 없음 → 이슈 등록 없음(D10-02).
- 범위: F1 회원·인증(AUTH-01~04), F2 프로젝트(PRJ-01·02·03·07-a), F3 멤버(PRJ-04·05·07-b), PRJ-08 역할 변경, F5 현황(DASH-01~04), TASK-08 드래그 앤 드롭(기능 동결 예외, 양준석 #132).
- A조가 만들지 않은 기능(업무·칸반·이력·댓글·검색, AUTH-06 화면)은 B조 검증 범위라 넣지 않았다.

## 2. 방법

- 환경: 로컬 Docker MariaDB + 백엔드(8000) + Vite(5179), Chrome(헤드리스)
- 실행할 때마다 새 계정(지수 OWNER · 민호 MEMBER · 서연 MEMBER · 현우 비멤버 · 비활성 계정 1개)과 새 프로젝트를 만들어 시연 데이터와 섞지 않았다.
- **화면**: 브라우저에서 입력·클릭(드래그는 실제 마우스 드래그, 빈 이름 오류는 실제 클릭으로 칸 이동).
- **API**: "다른 방법으로 시도해도 거절" 시나리오는 같은 요청을 API로 직접 보냈다.
- **DB**: AUTH-02-c 비활성 계정은 `is_active=0`으로 준비, AUTH-03-a는 `password_hash` 형식 확인, AUTH-04-b는 서버와 같은 키로 만료 토큰을 만들어 확인.
- 콘솔 오류: 없음

## 4. 참고

- 버그 없음. 검증 중 실패는 확인 스크립트 문제였다(프로젝트 0개일 때 생성 버튼 이름이 `첫 프로젝트 만들기`인 것, 헤드리스에서 스크립트 포커스 이동은 blur가 안 나는 것) — 화면 문제 아님.
