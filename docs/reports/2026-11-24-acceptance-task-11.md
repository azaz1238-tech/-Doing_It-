## 4. 참고

- 버그 없음 → 이슈 등록 없음(D10-02).
- 명세(API-SPEC §8)대로 달력은 `size=100` 응답 하나만 쓴다. 내 미완료 업무가 100건을 넘으면 나머지는 달력에 나오지 않는다(명세에 적힌 한계, 시연 범위에서는 문제 없음).
- 확인 안 함: 내 미완료 업무 100건 초과 경고(데이터 100건이 필요), 화면 읽기 프로그램용 글자("지연"·"임박"·"오늘" — 화면에 보이지 않는 글자라 수동 확인 범위 밖).
- 검증 데이터 정리(11/24): 프로젝트 `검증 달력 A`(23)·`B`(24)를 `DELETE /api/projects/{id}`로 삭제했다(204, 이후 조회 404, 업무·멤버 함께 삭제). 계정 `calcheck1`(19)·`calcheck2`(20)는 삭제 API가 없어 개발 DB에 남는다(소속 프로젝트·업무 0개). 없애려면 개발 DB를 비우고 seed를 다시 넣는다(`seed.py`는 빈 DB에만 넣으므로 DB를 먼저 비워야 한다 — SETUP §5 초기화 방법).
